# Douyin signatures

These scripts are executed inside the backend JVM through GraalJS; no HTTP signature service is required.

- `dy_ab.js` and `dy_live_sign.js` were migrated from the sibling `Tiktok-live` project at commit `28458197ffd10e7d0725acfcd4666c4ae80292e3`.
- `xbogus.js` is the existing general URL X-Bogus implementation previously hosted by `signature_web_project`.
